# Gizlilik politikası güncellemesi (SIWA token iptali için)

Sayfa: Notion → Geonaut — Gizlilik Politikası / Privacy Policy. Her dilde 3 değişiklik var.
Neden: hesap silinirken Apple izni iptal edilecek ve bu için küçük bir sunucu kullanılacak; mevcut "Bize ait bir sunucu yoktur" cümlesi bu durumda yanlış olur.

## 🇹🇷 TR
1. "Son güncelleme: 5 Ekim 2026" → **5 Kasım 2026**
2. "Bize ait bir sunucu yoktur; bu verilere biz erişemeyiz." → **"Oyun verilerinizi saklayan bir sunucumuz yoktur; bu verilere biz erişemeyiz."**
3. "Hangi ek hizmetler kullanılıyor?" listesine yeni madde ekle:
   - **Apple izninin iptali:** Hesabınızı sildiğinizde, Apple ile giriş izninizi iptal etmek için Apple'ın verdiği tek kullanımlık kod küçük bir sunucumuza iletilir. Sunucu bu kodu saklamaz; yalnızca iptal isteğini Apple'a iletir.

## 🇬🇧 EN
1. "Last updated: 5 October 2026" → **5 November 2026**
2. "We run no servers and cannot access this data." → **"We run no servers that store your game data and cannot access it."**
3. New bullet under "Which additional services are used?":
   - **Revoking the Apple permission:** when you delete your account, the one-time code provided by Apple is sent to a small server of ours so that your Sign in with Apple permission can be revoked. The server does not store this code; it only forwards the revocation request to Apple.

## 🇩🇪 DE
1. "Stand: 5. Oktober 2026" → **5. November 2026**
2. "Wir betreiben keine eigenen Server und haben keinen Zugriff auf diese Daten." → **"Wir betreiben keinen Server, der deine Spieldaten speichert, und haben keinen Zugriff auf diese Daten."**
3. Neuer Punkt unter "Welche zusätzlichen Dienste werden genutzt?":
   - **Widerruf der Apple-Berechtigung:** Wenn du dein Konto löschst, wird der von Apple bereitgestellte Einmalcode an einen kleinen Server von uns übermittelt, damit deine Berechtigung für „Mit Apple anmelden“ widerrufen werden kann. Der Server speichert diesen Code nicht; er leitet nur die Widerrufsanfrage an Apple weiter.

## 🇪🇸 ES
1. "Última actualización: 5 de octubre de 2026" → **5 de noviembre de 2026**
2. "No tenemos servidores propios ni acceso a estos datos." → **"No tenemos ningún servidor que almacene tus datos de juego ni acceso a ellos."**
3. Nuevo punto en "¿Qué servicios adicionales se usan?":
   - **Revocación del permiso de Apple:** al eliminar tu cuenta, el código de un solo uso que proporciona Apple se envía a un pequeño servidor nuestro para revocar tu permiso de inicio de sesión con Apple. El servidor no guarda este código; solo reenvía la solicitud de revocación a Apple.
